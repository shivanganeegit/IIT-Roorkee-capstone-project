## Model results (classification)

- **Blind baseline:** Validation accuracy = 0.7667. It predicts every parcel is on time, so it detects no delayed parcels (TP = 0, FN = 42, recall = 0, F1 = 0). With approximately 23% delayed parcels, its apparently reasonable accuracy is misleading and it is not useful for delay alerts.
- **Feature signal and noise:** The five bookkeeping/noise columns together account for 0.2244 (22.44%) of the 17-feature forest importance. All five noise columns fall outside the top seven by F-score. The seven highest F-score features are: distance_km, hub_tier, hub_daily_capacity, n_stops, promised_hours, rain_flag, sale_event_flag. See `part_c_feature_scores.csv` for each score, rank, and forest importance.
- **Number of selected features:** The `part_c_selectk.csv` report compares validation F1 for k = 5, 7, 10, 12, and 17. The selected configuration uses k = 7 as required. The table shows whether reducing the feature set improves F1 on this split; it does not guarantee the same ordering on new data.
- **Tuning:** The best tuned validation F1 (0.7848) was below the untuned forest (0.8333). On this validation set, tuning did not improve F1. Only 180 validation rows are available, so small F1 differences may reflect sampling variability. Cross-validation accuracy and validation F1 measure different things and should not be treated as interchangeable.
- **Alert threshold:** The chosen threshold is 0.5, selected as the highest tested threshold with validation recall at least 0.80 (or 0.1 if none qualifies). At this threshold, validation precision = 0.7955, recall = 0.8333, and F1 = 0.8140. Lowering the threshold generally catches more delayed parcels but can increase unnecessary alerts.
- **Final test evaluation:** At the same threshold of 0.5, test precision = 0.6889, recall = 0.7561, and F1 = 0.7209. Validation recall was 0.8333; test recall differs by -0.0772. The test set contains only 41 delayed parcels, so each additional missed or correctly detected delayed parcel changes recall by about 0.0244. The test set was not used to select the model or threshold.
